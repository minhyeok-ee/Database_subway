# 나만의 지하철 노선 저장 서버

이 프로젝트는 **지하철 전체 노선 데이터를 기반으로**

- 출발역과 도착역을 입력하면
- 가능한 최단 경로 후보를 여러 개 보여주고
- 그중 마음에 드는 경로를 **나만의 노선으로 저장**할 수 있는

Flask + SQLite 기반 웹 프로젝트입니다.

---

## 프로젝트 목적

보통 지하철 길찾기는

- 출발지와 도착지를 입력하면
- 가능한 경로들을 보여주고,
- 선택해서 세부 사항을 확인하면 경로를 확인할 수 있습니다.

여기서 추가적인 개선점을 덧붙여서

- 본인이 자주 사용하는 경로가 있거나
- 검색이라는 작업이 익숙하지 않은 인터넷 측면에서의 약자(어린이, 어르신)들도
- 사전에 원하는 경로를 저장하고 언제든 확인할 수 있는
- **경로 저장 시스템**을 만들고자 실행하였습니다.

## 데이터베이스 구조

### Station

모든 지하철 역 정보

| 컬럼         | 설명       |
| ------------ | ---------- |
| Station_id   | 역 고유 ID |
| Station_name | 역 이름    |

### Line

노선 정보

| 컬럼    | 설명      |
| ------- | --------- |
| Line_id | 노선 ID   |
| name    | 노선 이름 |

### Route

각 노선에서 역의 **순서 정보** (Sequence로 인접 역 연결)

| 컬럼       | 설명                 |
| ---------- | -------------------- |
| Station_id | 역 ID                |
| Line_id    | 노선 ID              |
| Sequence   | 해당 노선에서의 순서 |

### SavedRoute

사용자가 저장한 나만의 노선

| 컬럼             | 설명            |
| ---------------- | --------------- |
| id               | 저장 ID         |
| route_name       | 경로 이름(선택) |
| start_station_id | 출발역 ID       |
| end_station_id   | 도착역 ID       |
| path             | 역 이름 문자열  |

## 핵심 동작 로직

### 1) 지하철 그래프 구성 (Route -> Graph)

- `Route` 테이블을 읽고
- **같은 노선(Line_id)에서 Sequence가 연속인 역끼리 연결**
- 역–역 **양방향 그래프(adj)** 생성

---

### 2) 최단 경로 탐색 (BFS)

- 기준: **정차역 수(간선 수)**
- BFS로 최단 거리 계산
- 최단 거리 조건을 만족하는 **부모 노드 목록(parents)을 모두 저장**
- Backtracking으로 가능한 최단 경로 후보를 복원해서
- 최단 경로 후보(같은 거리)를 최대 5개까지 추출하여 보여줌.

---

### 3) 환승 지점 표시

- 인접한 두 역 (A, B)가 **같은 Line에 속하는지** DB에서 조회해서 후보 노선명 리스트를 얻음
- 이전 구간에서 타던 노선을 유지할 수 있으면 유지
- 노선이 바뀌는 지점은 `A -> B` 형태로 환승 표시

화면에서는 환승역을 **빨간색으로 강조**해서 보여줌.

---

## 화면 구성

### 메인 화면 (`/`)

- 프로젝트 메인 진입 화면
- 아래 두 기능으로 이동 가능
  - 나만의 노선 생성하기
  - 저장된 나만의 노선 보기

---

### 길찾기 입력 화면 (`/search/` – GET)

- 출발역 / 도착역을 입력하는 화면
- 사용자가 직접 역 이름을 입력
- 잘못된 입력(빈 값, 없는 역)은 에러 메시지 출력

---

### 길찾기 결과 화면 (`/search/` – POST)

- 출발역과 도착역 사이의 **최단 경로 후보들을 리스트로 출력**
- 하나의 경로가 아니라,
  - 여러 개의 최단 경로 후보를 동시에 제공
  - 보통 최단거리가 같은 여러 후보는 잘 존재하지 않아서 하나만 나올 가능성이 높음
- 각 경로별로
  - 정차역 수
  - 역 순서
  - 환승 지점 표시 (빨간색으로 강조)
- 각 경로마다
  - “이 경로 저장” 기능 제공

---

### 나만의 노선 저장 처리 (`/save_route/`)

- 검색 결과 화면에서 선택한 경로를 저장
- 저장 시 정보
  - 출발역
  - 도착역
  - 경로 문자열
  - 저장하고싶은 경로의 경로 이름
- 저장 완료 후 자동으로 **저장된 노선 목록 화면으로 이동**

---

### 저장된 나만의 노선 목록 (`/saved/`)

- 사용자가 저장한 모든 경로를 테이블 형태로 출력
- 표시 정보
  - 경로 이름
  - 출발역
  - 도착역
  - 전체 경로 노선
- 각 경로마다 삭제 기능 제공

---

### 저장된 노선 삭제 (`/delete/<route_id>/`)

- 선택한 저장 경로를 DB에서 삭제
- 삭제 후 다시 `/saved/` 화면으로 돌아감
